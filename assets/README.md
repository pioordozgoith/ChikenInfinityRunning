# Chicken Infinity Running

`Jogo de navegador` · `Endless runner` · `JavaScript` · `HTML5 Canvas` · `Pixel art` · `Retro` · `WebAudio`

Chicken Infinity Running é um jogo de corrida infinita em estilo retrô, desenvolvido em JavaScript puro com HTML5 Canvas. O projeto simula um runner de arcade 1-bit, com visual minimalista em pixel art, controles responsivos para teclado e toque, e um tema de console vintage.

## Visão geral

O jogador controla um personagem tipo galinha (ou um dos cinco tipos de "chicken" disponíveis), que corre infinitamente em um cenário futurista com obstáculos, moedas/ovos e desafios de tempo real. O objetivo é sobreviver o maior tempo possível, coletar ovos, acumular pontos e desbloquear itens adicionais.

## Recursos principais

- Gameplay de corrida infinita
- Personagens com diferentes aparências e estilos
- Obstáculos com necessidade de pulo ou desvio
- Sistema de pontuação e recordes locais
- Sistema de ovos/banco para compras e upgrades
- Chapéus e itens cosméticos desbloqueáveis
- Badge/achievements e ranking local
- Múltiplos temas visuais em 1-bit (monocromático, Game Boy, âmbar, Macintosh e cyber)
- Áudio gerado em tempo real com WebAudio
- Suporte a mouse, teclado e controles virtuais mobile

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API
- WebAudio API
- LocalStorage para salvar progresso e recordes

## Desenvolvimento

Este projeto está sendo desenvolvido com o Opencode e o modelo MIMO flash.

## Como executar

1. Abra o arquivo `index.html` em um navegador moderno.
2. Use:
   - Espaço, seta para cima ou toque no botão de pular para pular
   - Seta para baixo ou toque em deslizar para abaixar
   - P para pausar
   - C para trocar de personagem
   - M para alternar audio
   - T para trocar tema
3. Aproveite o jogo.

## Estrutura do projeto

- `index.html`: estrutura principal da interface do jogo
- `css/style.css`: estilos do console, telas e controles
- `js/game.js`: lógica principal do jogo, renderização, áudio, save data e sistema de progressão
- `assets/`: arquivos auxiliares e documentação

## Objetivo do projeto

O projeto funciona como uma experiência arcade divertida e visualmente nostálgica, misturando jogabilidade simples com muitos detalhes de interface e personalização. Ele é ideal para demonstração de game design em navegador, com foco em estética retrô, interatividade e mecânicas acessíveis.
